# Terra Compute - Free Publishing Targets

## Current Web Build

- Package: `release/terra-compute-html5-mobile.zip`
- Format: HTML5 ZIP
- Entry point: `index.html` at the ZIP root
- Recommended display mode: fullscreen or responsive embed

## Best Free Targets

1. itch.io
   - Best first launch target for the public web version.
   - Upload as `HTML Game` with the ZIP above.
   - Official HTML5 guidance: https://itch.io/docs/creators/html5

2. Game Jolt
   - Good secondary community target for free indie games.
   - Creator portal: https://gamejolt.com/creators

3. Newgrounds
   - Good for browser-game discovery if the game loads well in iframe/fullscreen.
   - Submission area generally requires login in the browser.
   - Creator/projects entry: https://www.newgrounds.com/projects/games

4. CrazyGames Developer Portal
   - Not just free hosting; it is a curated portal for browser games.
   - Best after the mobile version and first-time loading are polished.
   - Developer portal: https://developer.crazygames.com/

## Kaggle Game Arena

Kaggle Game Arena is not the right primary publishing format for Terra Compute as a playable HTML5 game. The public page describes it as measuring model capabilities through dynamic game environments, which fits AI agent evaluation rather than uploading a finished browser game.

Reference: https://www.kaggle.com/game-arena

## Submission Checklist

- One-line pitch: `A free retro-futurist strategy and puzzle game about the race to safe artificial superintelligence.`
- Build: `release/terra-compute-html5-mobile.zip`
- Controls: mouse, touch, keyboard shortcuts
- Platforms: web desktop and mobile browser
- Price: free
- Tags: strategy, simulation, educational, artificial-intelligence, retro-futurist, cold-war, card-game, puzzle
- Required media still missing before a serious public push:
  - capsule/banner image
  - 5 screenshots: desktop map, mobile map, faction select, puzzle screen, card/economy UI
  - short gameplay trailer or GIF
  - privacy note if analytics are added later
